# Examples by language

These are the names the original skills used for the generic wording in the solid skill.

| Generic wording | Language or ecosystem | Original example |
|-----------------|-----------------------|------------------|
| a type check before a call | JavaScript, TypeScript, Java | `instanceof` |
| a "not implemented" failure in an override | C# | `NotImplementedException` |
| business logic that imports a database driver, an HTTP client or the file system module | JavaScript, TypeScript on Node.js | `pg`, `mysql`, `axios`, `fs` |
| moving from one database to another | relational and document database products | PostgreSQL to MongoDB |
