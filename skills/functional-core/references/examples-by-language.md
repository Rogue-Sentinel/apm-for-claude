# Examples by language

These are the names the original skills used for the generic wording in the functional-core skill.

| Generic wording | Language or ecosystem | Original example |
|-----------------|-----------------------|------------------|
| an immutable update of an object | JavaScript, TypeScript | `{ ...obj, field: value }` |
| an immutable append to a list | JavaScript, TypeScript | `[...items, newItem]` |
| a sorted copy instead of sorting in place | JavaScript, TypeScript | `[...items].sort()` instead of `items.sort()` |
| operations that mutate a list in place | JavaScript, TypeScript | `sort()`, `splice()` |
| a binding that cannot be reassigned | JavaScript, TypeScript | `const` |
| the clock, randomness and the environment | JavaScript, TypeScript | `Date.now()`, `Math.random()`, `process.env` |
