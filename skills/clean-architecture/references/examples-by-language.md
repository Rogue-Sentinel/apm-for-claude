|-----------------|-----------------------|------------------|
| infrastructure libraries imported by the domain | JavaScript, TypeScript | `express`, `pg`, `axios` |
| a web framework | JavaScript, TypeScript on Node.js | Express, Fastify |

| a relational database | relational database products | PostgreSQL |
| a payment provider's client library | the payment provider's own library | Stripe SDK |
| a mail-sending library | JavaScript, TypeScript on Node.js | Nodemailer |
| extension functions | Kotlin, C# | Kotlin, C# |
